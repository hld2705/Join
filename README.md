# Join

A task management web application inspired by Kanban systems. Users can create, organize, and manage tasks through an interactive drag-and-drop interface.

## Live Demo

https://hld2705.github.io/Join/


## Features

- Drag & drop task management
- Responsive design
- User authentication
- Task categories and priorities
- Contact integration
- Interactive UI and animations

---

## Tech Stack

- HTML
- CSS
- JavaScript
- Firebase
